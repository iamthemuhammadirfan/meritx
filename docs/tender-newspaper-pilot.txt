Scope and costs

No uploads, supplier subscription, hosted OCR, paid AI API, paid proxy, or model
training. Python fetches dated publisher pages directly with verified HTTPS,
crawler-policy checks, one-second pacing (or the publisher's longer delay),
allowlisted redirects and bounded downloads. No paywall, login or CAPTCHA bypass.
Publisher access conditions still apply; internal use does not grant blanket
permission. Do not add sources that require circumvention.

Three newspapers, five coverage groups:
- Dawn: national/business pages plus Lahore and Islamabad metro pages. Other
  metro editions are excluded; this is not complete Dawn coverage.
- Jang: Lahore and Rawalpindi printed editions.
- Express: Lahore and Islamabad printed editions.
An Islamabad/Rawalpindi edition is a discovery source for federal notices,
not evidence that every notice is federal or that delivery is in that city.

Team access must be live first

Node uses individual accounts with scrypt password hashes, single-use 48-hour
invitations and opaque eight-hour sessions. Session digests, throttles, account
roles and invitation digests persist in a private JSON store. Passwords require
at least 12 characters. Account reset and disable revoke sessions; logging out
revokes the current session. Only an administrator can invite/reset/disable
others. A member cannot manage access, and the last administrator cannot be
disabled or downgraded. Self-reset through the team screen is blocked to avoid
losing the only administrator's activation link. There is no public signup and
no invitation email is sent. The administrator shares links through their own
channel. An account has one active session at a time during this pilot.

This file store supports ONE Node application process. Do not scale Passenger
to concurrent independent workers using the same team file. Bootstrap the
administrator before starting the process; use the team screen afterward.
For multi-process hosting, move credentials/sessions to a shared transactional
store before increasing instances. Back up team.json privately with its 0600
permissions. Offline account-owner recovery uses team.cjs invite-admin.

Free OCR and collection worker

Keep collection outside API requests and outside the document root. Use the
same private data directory and collector.lock as the official worker; overlaps
skip without modifying either job's database. Do not copy a local SQLite file
over production. The official worker can publish the same combined snapshot.

The worker supports two free backends. It uses a system Tesseract executable
when available; otherwise it runs the runtime bundled in the pinned tesserocr
wheel through ocr_worker.py. Both run in a child process with a 60-second OCR
timeout and one CPU thread. No root access, system package or AI API is needed
for the bundled backend. Both require the pinned English/Urdu language files.

Verified on the actual host on 23 November: CPython 3.13.18, x86_64, glibc 2.28.
The manylinux 2.27/2.28 tesserocr wheel and Pillow wheel load successfully.
Private test packages were installed under ~/.meritx-newspaper-pilot-stage/
packages using the existing permitted collector interpreter and pip --target.
This leaves the live collector's packages unchanged. The MCP allowlist rejects
the new staging virtualenv's interpreter; use the existing permitted private
collector interpreter, not arbitrary new executable paths. No policy changes
were made. During an approved production release, install the pinned worker
requirements into the existing private environment and verify it again before
scheduling. Account disk headroom was approximately 19.8 GB. Current LVE CPU
and memory limits were unavailable from MCP; zero values are not unlimited.
A one-page test measured roughly 50 MiB main-process peak RSS and 115 MiB
child-process peak RSS; this is a sample, not a full-run capacity guarantee.

Within the private Python environment:
  pip install --only-binary=:all: -r newspaper-requirements.txt
  python prepare_ocr.py --tessdata /PRIVATE_ENGINE/tessdata
prepare_ocr.py downloads only pinned free Tesseract English and Urdu language
files from the official repository, validates SHA-256 hashes and reuses valid
existing files. It makes no AI API call. The language files are Apache 2.0 data;
their source commit is recorded in prepare_ocr.py. Models are not Git assets.

Use a 20-minute outer job limit and a private log with bounded retention.
The worker normally has a 15-minute total budget, a fair budget per edition,

has a 60-second per-image timeout, one CPU thread and image pixel limits. Later

Results and limitations

Every collected page must match the requested publication date and edition.
Mapped clipping images are processed for Dawn and Jang, plus a full-page OCR
fallback. Express currently uses full-page OCR. A fallback can contain several
notices in one candidate; this is explicit unverified discovery, not a claim
that all tenders were separated correctly. Small or damaged Urdu ads can be
missed. Truncated publisher JPEGs can be decoded for review but flag coverage
partial. Run limits, failed page checks and failed clipping checks also remain
partial rather than reporting zero opportunities or complete coverage.

Source metadata, seven dated coverage rows, expected/fetched/processed page
counts and candidate counts are shown in Sources. Some days can be partial;
processing every page does not measure advertisement recall. No manual paper
upload is needed. Staff can inspect uncertain extracted text and private OCR
images in Newspaper review. Dates from OCR are never installed as submission
deadlines. Company eligibility remains unassessed. A city mentioned in the ad
is labeled separately from verified delivery location. Newspaper references
are not used to merge records with official tenders until verified. Identical
image candidates deduplicate within a page, but cross-paper duplicates can
remain during the pilot to avoid false merges. Revisions keep their evidence.

The feed and evidence need authenticated, private/no-store responses. Assets
contain no account secrets or catalog records. Evidence is only reachable by
authenticated fixed-hash routes, never arbitrary paths. Raw data, OCR cache,
SQLite and images live outside every document root. Evidence has a 512 MB
ceiling and a 12 MB per-image ceiling; hitting either reports partial coverage.
Inspect size after the pilot, back up deliberately and remove test artifacts
according to retention needs. No unlimited archive or paid storage is assumed.
